## Decisions / changes (uncommitted on main)
- middleware.ts: /flashcards, /lessons, /vocabulary removed from PROTECTED + matcher (guest access). /dashboard, /profile, /quizzes, /exam-prep still require login.
- CRITICAL fix — public/sw.js: was cache-first for ALL same-origin GETs incl. HTML pages → stale HTML/JS after any rebuild or deploy → React never hydrated, nothing clickable (flashcards, search, etc.). Now: network-first for pages, cache-first only for hashed /_next/static/*, never caches RSC payloads / HMR. Cache bumped kalbalab-v2 → v3 so existing visitors' stale cache is purged on next visit.
- app/ClientProviders.tsx: service worker registers only in production; in dev it unregisters any old worker and clears kalbalab-* caches.
- Page titles: new layout.tsx with metadata for flashcards, vocabulary, lessons (covers a1 subpages), login, register (previously all showed the default title).
- New app/not-found.tsx (branded 404 with links) — was the bare Next.js default.
- Accessibility: login/register/contact labels linked to inputs (htmlFor/id); autocomplete current-password / new-password / name / email; vocabulary save buttons got aria-label + aria-pressed; footer newsletter input got aria-label.
- Contact name placeholder "Arman" → "Your name".
